Features and how-to

Write Markdown without leaving your browser

ConText Editor is a private, local-first workspace for people who want a calm place to write notes, documentation, and code. It combines a Markdown source editor with a rich writing view while keeping your work on your device.

What the editor does

Switch between Markdown and Rich views

Use the Markdown view for precise syntax and the Rich view for readable formatting. Headings, lists, links, tables, task lists, images, and code blocks stay part of one note.

Preview diagrams and formatted content

See Markdown as you write, including Mermaid diagrams and formatted code. A local diff checker also helps compare text, JSON, YAML, and SQL without sending files to a server.

Keep notes local and recoverable

Notes, history, Trash, and appearance settings use browser storage. Import Markdown files, export your work, and create backups when you need to move between devices or profiles.

How to use ConText Editor

  1. Open the editor and select New note.
  2. Write in Markdown or switch to Rich for visual editing.
  3. Use preview, focus mode, and the writing-width control to shape your workspace.
  4. Import, export, or back up notes from the note library tools.

Who it is for

ConText Editor is for developers documenting projects, writers drafting ideas, researchers keeping private working notes, and anyone who prefers plain-text portability over an account-based workspace. It is not a cloud collaboration suite: there are no shared accounts, comments, or server-side sync.
