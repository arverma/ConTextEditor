Features and how-to

Write Markdown without leaving your browser

ConText Editor is a private, local-first workspace for people who want a calm place to write notes, documentation, and code. It combines a Markdown source editor with a rich writing view while keeping your work on your device. This guide walks through each feature with short steps and keyboard shortcuts.

Features and how to use them

Switch between Markdown and Rich view

Work in raw Markdown for precise syntax, or in Rich view for readable formatting. Both views edit the same note.

  1. Open or create a note.
  2. Select the view toggle in the top bar, or press the shortcut below.
  3. Edit in either view; headings, lists, tables, task lists, links and code blocks carry over.

Shortcuts: Toggle Markdown / Rich Ctrl/⌘ + E.

Create, search and organise notes

Every note is saved in your browser as you write, and the history panel lists them all so you can find one quickly.

  1. Select New note, or press the shortcut.
  2. Open the history panel to browse your notes.
  3. Type in the note search box to filter by text.

Shortcuts: New note Ctrl/⌘ + Shift + Enter; Toggle note history Ctrl/⌘ + \; Search notes Ctrl/⌘ + Shift + F; Save note Ctrl/⌘ + S.

Preview formatted content and diagrams

See formatted Markdown, highlighted code and Mermaid diagrams while you write.

  1. Add a fenced code block with the language mermaid.
  2. Write your diagram definition inside the block.
  3. Check the rendered diagram in the preview, and open it in the viewer to zoom.

Compare text with the Diff Checker

The local diff checker compares two pieces of text, JSON, YAML or SQL entirely in your browser.

  1. Open the Diff Checker.
  2. Paste the original text on one side and the changed text on the other.
  3. Format both panes if the content is JSON, YAML or SQL, then review the differences.

Shortcuts: Open Diff Checker Ctrl/⌘ + Shift + D; Format Diff Checker panes Alt + Shift + F.

Focus mode and writing width

Remove distractions and choose a comfortable line length for long writing sessions.

  1. Turn on focus mode to hide surrounding panels.
  2. Toggle full width to let text use the whole window, or toggle it back for a narrower column.

Shortcuts: Toggle focus mode Ctrl/⌘ + Shift + O; Toggle full width Ctrl/⌘ + Shift + W.

Copy and export your work

Copy the Markdown source, or export the current view when you want to share a note.

  1. Open the note you want to share.
  2. Select the export control, or press the shortcut to copy Markdown or export a PDF of the current view.

Shortcuts: Copy Markdown Ctrl/⌘ + Shift + C; Copy Markdown / Export PDF (current view) Ctrl/⌘ + Shift + E.

Import, back up and restore

Bring in existing Markdown files and keep backups so notes can move between devices or browser profiles.

  1. Choose Import Markdown files to add .md files as notes.
  2. Choose Download complete backup to save all notes and Trash as a JSON file.
  3. On another device or profile, choose Restore backup and select that file.

Recover deleted notes from Trash

Deleting a note moves it to Trash, so a mistake is not final until you empty it.

  1. Delete the current note.
  2. Open Trash to see removed notes.
  3. Restore a note, or choose Delete forever to remove it permanently.

Shortcuts: Open Trash Ctrl/⌘ + Shift + T; Delete current note Ctrl/⌘ + Shift + Backspace.

Light, dark and system themes

Match the editor to your surroundings or follow your operating system.

  1. Use the theme control in the editor, or press a shortcut to switch directly.

Shortcuts: System theme Alt + Shift + 1; Light theme Alt + Shift + 2; Dark theme Alt + Shift + 3.

Frequently asked questions

Does ConText Editor upload or sync my notes?

No. Notes, history and Trash live in your browser's storage on this device. The website host only serves the app files. There is no account, analytics or tracking.

How do I move my notes to another device?

Use Download complete backup from the note library tools, then choose Restore backup on the other device. Backups are unencrypted JSON files, so keep them somewhere you trust. You can also export single notes as Markdown.

What happens if I clear my browser data?

Clearing this site's data removes your notes and Trash, because they are stored only in the browser. Download a backup first if you want to keep a copy.

Can I recover a note I deleted?

Yes. Deleted notes move to Trash first. Open Trash, restore the note, or choose Delete forever to remove it for good.

What is the difference between Markdown and Rich view?

Markdown view shows the raw source with syntax. Rich view shows the same note formatted, with headings, lists, tables and code blocks. Both edit one note, and you can switch at any time.

Does the editor support diagrams?

Yes. Mermaid diagrams are rendered in the preview, and you can open them in a larger viewer.

Can I collaborate with other people in real time?

No. ConText Editor is a single-user, local-first tool with no shared accounts, comments or server-side sync.

Who it is for

ConText Editor is for developers documenting projects, writers drafting ideas, researchers keeping private working notes, and anyone who prefers plain-text portability over an account-based workspace. It is not a cloud collaboration suite: there are no shared accounts, comments, or server-side sync. Read the ConText Editor privacy policy for details on how your data is handled.
